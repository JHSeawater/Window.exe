# WINDOW.exe — 구현 체크리스트 과거 검증

> 2026-10-31 문서 정리 시 보존한 과거 기록이다. 당시 계획·확인 결과이며 현재 구현 완료를 뜻하지 않는다.

### 18-1. 착수 기반 구현·검증 기록

0a의 Windows 입력 검증 이후 두 페이즈·전환·인계 API와 단독 Windows 빌드를 마련했다. 현재는 5단계의 수동 플레이·가독성·실제 앞뒤 연출 통합을 남겨 두고 있다. 코드와 실행법은 [개발 가이드 17-10장](../DEVELOPMENT.md#17-10-착수-구현과-검증-도구--2026-10-31)에 두며, 아래의 기반 시험 통과를 두 페이즈 구현 완료로 취급하지 않는다.

- [x] 입력 부분 상태/원본 순서/누른 입력 소비/늦은 해제 취소, 빠른 상대 이동·리사이즈·접선·구간 합집합, 누적 시계·복수 정지·동시 우선순위, 관리자/geometry/좌표/CRT 및 Desktop 진입·실패·엔딩 허용의 기반 자동 시험 **30/30 통과**. `Builds/BossFight/stage0-tests.json`에 기록했다. 이 수치는 착수 기반의 기록이며, 이후 게임 상태까지 연결한 검증은 아래에 별도로 기록했다.
