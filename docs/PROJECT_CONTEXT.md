# WINDOW.exe — 프로젝트 배경과 게임잼 조건

> 역할: 이 프로젝트를 만드는 배경, 행사 조건과 심사 기준을 기록한다.
> 기준일: 2026-10-30. 행사 정보는 기존 문서의 OT 자료 기록을 옮겼다.
> 문서별 역할과 상태 표기는 [README](../README.md)를 따른다.

## 1. 참가 배경

2026 경북 Gen AI Game JAM(10/30~11/1, 경주교원드림센터) 출품을 위한 프로젝트다. 완성작 전체를 만드는 것보다 **핵심 플레이가 실제로 작동하는 프로토타입**을 목표로 한다.

엔진은 팀원 전원이 익숙한 **Unity [확정]**를 사용하며 환경 세팅은 팀이 직접 한다. 구체적인 버전·프로젝트 열기는 [개발 가이드](DEVELOPMENT.md)에서 관리한다.

## 4. 프로젝트의 제작 방향

**안정적으로 돌아가는 짧은 한 판을 분량보다 우선한다.** 게임의 핵심 경험을 실제로 보여줄 수 있는 범위에서 기획한다.

게임의 내용은 [GDD](GDD.md), 작업과 담당은 [구현 체크리스트](IMPLEMENTATION_CHECKLIST.md), 구체적인 우선순위·일정·시연은 [제작 계획](PRODUCTION_PLAN.md)에서 다룬다.
