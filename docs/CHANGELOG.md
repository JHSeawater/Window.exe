## 2026-10-31 — QA-01~03 수정과 검토 보완 반영

- 사용자 구현 지시에 따라 표시/일반 geometry를 분리하고 전체 조작 상태의 캡처·취소 복원, 변경 축별 리사이즈와 공개 절대/상대 API 계약을 구현했다.
- 외형 재초기화가 관리자 정렬을 다시 적용하고, 완성된 외형에서 작업 표시줄 알림을 보내도록 보완했다. 현재 인스턴스 검사와 재진입 정책은 유지한다.
- 창 평면·좌표 계산의 유효 상태를 함께 캐시하고 무효 전환의 취소·입력 거부·복구를 보완했다. 같은 프레임의 취소된 누름/해제가 새 클릭으로 처리되는 경우도 재현 후 수정했다.
- 기존 변경 13개 파일과 수정 전 실패 결과를 보관했다. 기존 63개와 신규 10개, 전체 73개 시험이 통과했다. 실제 빌드·기동·직접 조작 범위와 미확인 항목은 체크리스트 15-4장에서 구분한다. 시작 메뉴·퍼즐·엔딩은 추가하지 않았다.
