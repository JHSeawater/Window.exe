# WINDOW.exe — 문서 변경 이력

> 역할: 문서 구조와 결정이 바뀐 이유를 기록한다. 현재 요구사항과 진행 상태는 각 원본 문서에서 관리한다.
> 기존 GDD·PROJECT_CONTEXT의 이력을 아래에 보존했다. 과거의 범위·담당 기록은 현재 결정을 뜻하지 않는다.

## 2026-10-30 — 추가 구현과 폴더 정리 공유 변경

- 사용자 커밋·푸시 요청으로 영역 선택·묶음 이동, 역할별 에셋 경로와 `.meta`, 제공 배경·폰트, 테스트와 관련 문서를 하나의 공유 변경으로 정리했다.
- 이전 항목의 미커밋 표기는 각 작업 당시 상태다. 현재 문서의 경로·기능·검증 기록은 이번 공유 변경을 기준으로 갱신했다.
- 빌드·로그·프로토타입 보관본과 다른 로컬 아트는 기존 Git 제외 규칙을 유지한다. 검증은 폴더 이동 후 테스트 33개 통과, Windows 빌드 경고·오류 0과 두 해상도 시작 확인 기록을 기준으로 한다.

## 2026-10-30 — Assets 역할별 폴더 정리

- 사용자 요청으로 `Assets/Desktop`의 런타임·에디터·테스트·프리팹·데이터·씬을 각 역할 폴더 아래의 Desktop 기능 위치와 `Assets/Scenes/Desktop.unity`로 이동했다. 임시 수신기는 런타임의 Debug 하위에 분리했다.
- Unity AssetDatabase로 `.meta`와 GUID를 보존하고, 클래스·네임스페이스·어셈블리 이름 및 참조를 유지했다. 비워진 이전 폴더와 폴더 메타만 제거했다.
- 사용자 제공 루트 폰트를 `Assets/Art/Fonts/neodgm.ttf`로 분류했다. 폰트·배경 원본 내용은 보존했으며 실행 글꼴은 교체하지 않았다.
- 새 경로에 맞춰 생성 도구·공유 씬 테스트·Git 허용 경로·실행 안내·AGENTS 지침을 갱신했다. 다른 로컬 아트와 빌드·보관본의 제외는 유지한다.
- 이동 후 자동 검증 33개와 두 해상도의 공유 씬 조작을 재확인하고, 새 씬 경로의 Windows 빌드를 경고·오류 0으로 완료했다. 이번 정리는 아직 커밋·푸시하지 않았다.

- GDD에는 사용자 조작 규칙만 반영하고 구현 구조·현재 작업 트리 결과·후속 범위는 각 담당 문서에 기록했다. 이번 추가 구현은 아직 커밋·푸시하지 않았다.
